# ITCHY Windows Troubleshooter v1.3.0

Bu surum tarama motorunu, sonuc anlatimini ve teknisyen raporunu daha guvenilir hale getirir.

## One Cikanlar

- Bulgular kok neden adayi, dogrudan ariza, cokme kaniti, yapilandirma, izleme ve sonuc olayi olarak ayrilir.
- Eski ve tek kaynakli kayitlar daha dusuk guvenle puanlanir; yuzde 90 ustu sonuc guclu veya cok kaynakli kanit gerektirir.
- Kernel-Power 41 artik kok neden olarak sunulmaz; beklenmedik kapanmanin sonuc kaniti olarak tutulur.
- Zaman eslesmesi olmayan Code Integrity kayitlari mavi ekran nedeni kabul edilmez.
- Uygulama, servis ve surucu hatalari bilesen bazinda gruplanir.
- Kisa analiz sonucu bilesen, guven, tekrar, guncellik, mavi ekran iliskisi ve ilk islemi birlikte gosterir.
- Disk/SMART, pagefile, dump ayari, Windows Bellek Tanilama, bekleyen yeniden baslatma ve DISM saglik denetimleri rapora eklenir.
- Tarama asamasi arayuzde canli gosterilir; baslatma, iptal ve rapor dugmeleri islem durumuyla uyumlu calisir.
- HTML raporda ilk uc bulgu acik, ayrintili ve ham kayitlar kapali gelir.
- Bulgu kartindan ilgili hata kayitlarina gecilip otomatik arama yapilabilir.
- Sistem Koruma sorgusu genel taramanin tamamlanmasini engellemez.
