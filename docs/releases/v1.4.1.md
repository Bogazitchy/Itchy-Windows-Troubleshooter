# ITCHY Windows Troubleshooter v1.4.1

## Yeni Marka Görünümü

- Kullanıcının sağladığı orijinal ITCHY logosu uygulamaya eklendi.
- Ana marka alanı ve Ayarlar bölümü logoyu koyu temada okunabilen açık bir zeminde gösterir.
- EXE, pencere ve görev çubuğu için 16, 24, 32, 48, 64, 128 ve 256 piksel ICO kaynağı eklendi.
- README yeni logo ve güncel indirme bağlantısıyla yenilendi.
- v1.4.0 analiz ve güvenlik geliştirmeleri korundu.

## Paket

`ITCHY-Windows-Troubleshooter-v1.4.1-win-x64.exe`: Windows 10/11 x64, self-contained, tek dosya.
`SHA256SUMS.txt`: EXE bütünlük özeti.

Windows eski simgeyi önbellekte tutarsa yeni sürüm adındaki EXE'yi kullanın ve görev çubuğundaki eski sabitlemeyi güncelleyin.
